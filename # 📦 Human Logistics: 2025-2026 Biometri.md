An independent field study and data science project bridging the gap between warehouse floor operations and physiological telemetry. This repository serves as the **Project Hub** for the 2024-2025 UPS Peak Season Biometric Audit.

## 🔭 Project Ecosystem

This project is distributed across three primary pillars to ensure data integrity and accessibility:

1.  **[The Dashboard (Live Analysis)](https://logistics-performance-analysis-2025.vercel.app/):** An interactive Next.js interface featuring real-time data visualization and **WatchBot**, an AI assistant trained on the audit's specific findings.
2.  **[The Data (Kaggle Repository)](https://www.kaggle.com/code/gastondana/exploratory-analysis-quantifying-human-cost-final):** The source truth. Contains the Python-based Exploratory Data Analysis (EDA), Pearson correlation matrices, and the raw biometric JSON telemetry.
3.  **[The Identity (ORCID)](https://orcid.org/0009-0007-1011-860X):** Formal researcher verification and project citation record.

## 🛠 The Tech Stack

-   **Frontend:** Next.js 14, Tailwind CSS, Lucide React (Industrial-Dark UI).
-   **Data Processing:** Python, Pandas, Seaborn (Correlation Heatmaps).
-   **Hardware:** Samsung BioActive™ Sensor Suite (PPG + 3-Axis Accelerometry).
-   **Intelligence:** Hybrid AI/Expert System (WatchBot) for biometric interpretation.

---

## 📊 Key Findings

-   **Intensity Correlation:** Identified a **0.84 correlation** between `Strain Index` and `Intensity Density`, proving that work pace is a higher predictor of fatigue than total duration.
-   **The Movement Paradox:** Data from Dec 10th revealed that peak step counts (8,103) do not always equate to peak physiological strain, highlighting the impact of operational delays.
-   **Peak Volumetrics:** Dec 4th recorded the highest metabolic toll of the audit window ($9.90$ cal/min intensity density).
